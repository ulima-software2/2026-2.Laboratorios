# Taller Práctico: Principios de Diseño y Buenas Prácticas en Java

**Curso:** Ingeniería de Software  
**Lenguaje:** Java 17+  
**Objetivo:**  Identificar y aplicar patrones de diseño estructurales.

---

## Estructura del Taller

| Ejercicio | Temas Tratados 
| :--- | :--- |
| **Ejercicio 1** | Alta Cohesión, Bajo Acoplamiento y SRP (* ibility Principle*) |
| **Ejercicio 2** | Ley de Demeter, Principio KISS (*Keep It Simple, Stupid*) y YAGNI (*You Aren't Gonna Need It*) |
| **Ejercicio 3** | Principio DRY (*Don't Repeat Yourself*) y Simulación de *Duck Typing* en Java |
| **Ejercicio 4** | Principio SOLID: OCP (*Open/Closed Principle*) |
| **Ejercicio 5** | Principio SOLID: LSP (*Liskov Substitution Principle*) || **Ejercicio 6** | Principios SOLID: ISP (*Interface Segregation Principle*) y DIP (*Dependency Inversion Principle*) |
